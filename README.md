# ApexPlanet Task 2 - Responsive Login & Registration UI

A modern responsive Login and Registration interface developed for the ApexPlanet Full Stack Web Development Internship.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Google Fonts
- PHP
- AJAX

## Features

- Responsive navigation bar
- Responsive Login interface
- Responsive Registration interface
- Password show/hide functionality
- Client-side form validation
- Password confirmation validation
- Username and email availability check
- Bootstrap 5 responsive grid
- Smooth scrolling
- Hover effects and animations
- Mobile-first responsive design

## Project Structure

- `index.html` - Main webpage
- `style.css` - Custom styling and responsive design
- `script.js` - JavaScript interactions and validation
- `check.php` - AJAX availability-check endpoint
